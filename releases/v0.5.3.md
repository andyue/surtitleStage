SubtitleStage v0.5.3（build 13）新增 Glypheo 字幕專案匯入，並公開完整專案原始碼。

## 下載與使用

下載 **SubtitleStage-0.5.3-build13.dmg**，將 App 拖到「應用程式」。支援 macOS 14 以上，Universal（Intel / Apple Silicon）。此版本採 ad-hoc 簽名，未經 Apple notarization。

File → Import Document → 選擇 `.glypheo` → 將各 Track 映射到 Surtitle → Preview → Review Changes → Apply Checked Changes。

## 新增功能

- 按 Group 與 Cue 原順序匯入多 Track 文字，保留 Unicode、空白與換行。
- 群組名稱可保留為備註，Cue 編號依文件順序產生。
- 預覽中可將 Track 映射到既有或新建 Surtitle；確認後一次套用，可 Undo。
- 來源停用 Cue 與全空白 Cue 預設忽略，可於預覽逐列啟用。
- 使用穩定來源 ID 重新匯入，保留既有 Cue UUID，沿用衝突檢查與 Live Cue 保護。

## 驗證與限制

- 完整測試 103 項，12 項環境相關跳過，其餘通過；額外重新匯入測試通過。
- 本機實際製作檔案驗證：2,839 個 Cue、2 個 Group、4 個 Track。演出檔案不包含於原始碼或安裝檔。
- Intel／Apple Silicon Release 編譯、Universal 封裝與簽名驗證通過。
- 目前為純文字移轉：Glypheo 字型、字元樣式、轉場、群組階層、Panel 與輸出設定不移轉；匯入後請檢查 Layout。
- 尚未完成此增量的人工 UI／IME 與實體輸出驗收；其他 Glypheo 檔案版本尚待更多樣本驗證。
