SubtitleStage v0.5.2（build 12）整合自 v0.3 以來的多輸出 Mapping、文件匯入／匯出，以及 Syphon／NDI 網路與跨軟體影像輸出。

## 下載與安裝

下載下方 **SubtitleStage-0.5.2-build12.dmg**，將 App 拖到「應用程式」。支援 macOS 14 以上，Universal（Intel / Apple Silicon）。

這是 ad-hoc 簽名的開發版本，尚未經 Apple notarization。若 macOS 阻擋，請依系統提供的「打開」／隱私權與安全性流程處理。本儲存庫目前提供安裝檔；GitHub 自動產生的 Source code 壓縮檔不包含此版本 App 原始碼。

## v0.3 — Canvas 與多輸出 Mapping

- 自訂 Canvas 尺寸與 Presets，支援非標準比例。
- 每個 Output 獨立設定啟用狀態、顯示器、訊號解析度與字幕 Layout。
- Region 來源裁切與目的地位置／尺寸，支援拖拉、縮放及精確數值設定。
- Fit、Fill、Stretch、1:1 Pixel 模式與實體輸出像素檢查。
- Playback 預覽依欄寬扣除邊界縮放，保持畫面比例。

## v0.4 — 文件匯入、重新匯入與 XLSX 匯出

- File 選單整合 Import／Re-import，新增 Cue Sheet 與匯入範本 XLSX 匯出。
- XLSX 多工作表、標題列選擇、自由欄位映射與確認預覽；不依賴固定欄名。
- 欄位可映射既有 Surtitle，或直接建立 New Surtitle，一次 Apply 並可 Undo。
- **Merge by Cue Number**：同一 Show 的不同語言可依 Cue Number 合併到相同 Cue，保留 Cue UUID；不再因分次匯入不同 Surtitle 而額外建立同編號 Cue。歧義／重複編號會阻擋。
- 具有穩定來源 ID 的 XLSX 可重新匯入，比較未變／修改／新增／刪除；本機衝突與刪除需逐項確認，保留既有 UUID、格式、配置與轉場。
- DOCX 段落、角色／台詞、表格儲存格、標題與整段一致的粗體／斜體／底線辨識。
- Import Workspace 提供編輯、Split／Merge、Ignore、Speaker／Layer 指派、重新編號與驗證；背景解析、確認後一次套用並可 Undo。

## v0.5 — Syphon 與 NDI®

- 每個 Output 可建立獨立 Syphon Server，支援透明背景、30／60 fps、Opacity、Fade／Blackout。
- v0.5.1 修正 Syphon 發送端垂直座標轉換，處理 QLab 回報的反向畫面；保留左右文字順序。
- **v0.5.2 新增 NDI High Bandwidth video sender**：多來源、來源命名、透明／不透明背景、30／60 fps、Fade／Blackout、接收連線數顯示。
- Syphon／NDI 沿用 Output 的 Layout、Canvas 與 Region Mapping，不必指派實體螢幕；背景傳送不阻塞播放命令。
- 操作：**Edit → Video Output → Enable Syphon／NDI → Start → GO**。Start 本身不會將選取 Cue 播出。
- NDI runtime 為可選依賴，不包含在安裝檔；可自動使用已安裝的官方 Runtime／部分 NDI Tools，或手動選擇 libndi.dylib。缺少時只回報 NDI 不可用，不影響其他播放功能。
- NDI 需偶數訊號寬度；遇到奇數 Canvas 請明確設定 Output signal resolution，不會自動更改 Canvas。若 macOS 詢問，需允許本機網路存取。

## 相容性與限制

- 專案格式升至 **11**，可讀取並遷移格式 1–10；舊版 App 無法讀取新格式，請先 **Save As** 保留舊檔。
- 本版僅傳送影像，不含 NDI 音訊、圖片／影片 Layer。
- Excel 使用已儲存的公式結果，不重新計算。DOCX 混合字元樣式會提示後攤平；不提供 DOCX re-import。
- 匯入工作區的 Split／Merge 不代表正式 Cue List 已有 Split／Merge 功能。
- Stop Syphon／NDI 後接收端可能停留在最後一幀；需要清場時先 Blackout，再 Stop。
