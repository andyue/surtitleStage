SubtitleStage v0.5.4（build 16）。

## 下載與安裝

下載 **SubtitleStage-0.5.4-build16.dmg**，將 App 拖到「應用程式」。最低部署版本 macOS 13，Universal（Intel / Apple Silicon）。採 ad-hoc 簽名，未經 Apple notarization。

## 更新內容

- 新增 **2 Left / 2 Right** 版面選項，記住這台 Mac 的選擇。
- **Float Show Controls** 將控制區獨立為置頂視窗；Playback 預覽留在主視窗。關閉浮動視窗或選擇 **Dock Show Controls** 即可放回，不停止輸出。
- 可自訂 Show Controls 熱鍵，預設 **Space = GO / Next、Esc = Stop Output**；僅控制區取得焦點時作用，保留文字輸入與中文 IME 優先權。
- 文件匯入整合成單頁流程，簡化來源欄位設定。
- 移除 Cue Details 分頁，新增 File → Open Recent。
- 支援負行距及字幕框超出 Canvas；改善字幕選取框。
- Blackout fade 預設為 1 秒。
- 改善編輯分頁、字型選單與 Cue 表量測效能，減少重複輸出設定檢查。
- App、Syphon framework 與 Metal shader 部署目標調整為 macOS 13。

## 驗證狀態

- 完整自動測試 114 項，5 項環境／樣本相關跳過，零失敗。
- 浮動視窗生命週期、焦點與熱鍵防護測試通過；額外原生版面渲染測試通過。
- Intel／Apple Silicon Release 建置、Universal 封裝、簽名與 DMG checksum 驗證通過。
- macOS 13、原生 Apple Silicon、完整人工 UI／IME 與實體輸出驗收仍待完成。
