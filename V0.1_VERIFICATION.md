# V0.1 verification

> 歷史紀錄：以下描述當時版本與當時驗收狀態。現行 Live 即時編輯、Escape 行為、OSC 及 2026-10-18 人工驗收結果，請以 README.md、OSC.md、SURTITLE_WORKFLOW_VERIFICATION.md 為準；不要直接使用本文件作為現版驗收清單。
Historical baseline. The later user-requested multilingual table and Layout extension is documented in `LAYOUT_VERIFICATION.md`.

## Environment inspected

- Repository initially contained PROJECT_SPEC.md, ROADMAP.md, AGENTS.md, and empty source/test folders.
- No Git repository or pre-existing build/test target was present.
- Xcode 26.5, Swift 6.3.2, macOS 26.6.2, Intel x86_64.
- Deployment target: macOS 14.

## Incremental checks

1. Core package: debug build passed; 8 tests passed.
2. Operator UI and persistence: debug build passed; 8 tests passed.
3. Output, keyboard, lifecycle, and app integration: debug build and 13 tests passed. An initial Swift 6 event-monitor Sendable error was corrected. The offscreen renderer test was corrected to use a flipped AppKit graphics context matching the actual view.
4. Release bundle: release build and strict ad-hoc signature verification passed. iCloud repeatedly reattached Finder metadata to an in-repository `.app`, so packaging now stages the signed app outside iCloud and produces a ZIP archive in `.build`.
5. Startup smoke: the release executable remained running for five seconds with no stdout/stderr diagnostics when launched outside the restricted shell; the test instance was then terminated. The restricted-shell attempt aborted in macOS application registration before app UI initialization. This smoke test does not verify interactive UI behavior.
6. Renderer: offscreen native raster output was visually inspected with Traditional Chinese, Simplified Chinese, English, Japanese, and Korean on a 2688 × 768 canvas. Automated checks verified visible glyph pixels and fully black blackout output.

## Automated coverage

- Empty, first, last, next, and previous playback boundaries.
- Selection/live separation and live snapshot isolation from edits.
- Blackout restoration and GO during blackout.
- Cue UUID preservation and reorder behavior.
- Unicode clipboard import, newline normalization, line/paragraph splitting.
- Import preview isolation and explicit mutation on confirmation.
- Unicode/style/canvas/output serialization, deserialization, and atomic file replacement.
- Rejection of malformed data, unsupported format versions, invalid canvases, and duplicate cue IDs.
- Arbitrary canvas aspect ratios and bidirectional coordinate conversion.
- Editing/modal/window/modifier shortcut guards and playback key mapping.
- Store deletion protection for live cues.
- Shared native text rendering and blackout raster output.

## Manual acceptance — not yet verified

- [ ] Launch the app; verify layout at the operator's screen size, including the scrollable editor.
- [ ] Add/edit/delete/reorder cues. Save, reopen, and compare UUIDs, ordering, notes, font settings, and text.
- [ ] Exercise New/Open/Close/Quit with Save, Discard, and Cancel; cancel Save As; verify no unintended data loss. Reopen the operator window from the Window menu.

- [ ] With Traditional Chinese and Simplified Chinese IMEs, compose text in subtitle, name, number, and notes fields. Use Space, Enter, arrows, Escape, and B; verify candidate selection and composition are untouched by playback shortcuts.
