# SubtitleStage v0.5.4 (build 15) — 2026-11-12

## Implemented

- Layout correction: Cue list occupies the left pane; Edit is top-right and Playback / Show Controls is bottom-right, separated by a draggable divider.
- Cue Details UI and its obsolete editor removed; persistent metadata remains readable and is not destructively deleted.
- Configurable local Show Controls hotkeys, conflict validation, Clear/Restore Defaults, persistence and editing/IME/modal/auto-repeat guards. Defaults: Space = GO/Next, Escape = Stop Output. Playback requires Show Controls focus. Output windows retain Escape and double-click exit; Space does not advance output from an output window.
- File → Open Recent: up to ten successfully opened/saved project paths, deduplication, Clear Menu, missing-file error without replacing the active project.
- One-page import: automatic initial track mapping, preview and a single Import action. Source ID and Cue Number are automatic; group/status metadata is ignored. Blank/disabled cues default to skipped. Re-import/number-merge conflict and live-cue protection remain in the existing atomic import pipeline.
- Negative line spacing uses actual fixed line-height constraints rather than relying on AppKit to accept a negative lineSpacing value.
- Source subtitle positions may exceed Canvas bounds. Model geometry remains canvas-pixel coordinates; rendering still clips to Canvas/Region. Selection borders use text height; existing stored text position is unchanged. Newly created primary layers have the same compact default geometry as other layers.
- Blackout fade defaults to 1 second. Explicit values stored in existing projects are preserved.
- Project format 12 explicitly expands permitted line spacing and source-layout coordinates. Formats 1–11 migrate without changing their stored values. A project saved as format 12 requires this or a newer app.

## macOS deployment

- Package target, both release triples and Info.plist minimum: macOS 13.
- Rebuilt pinned Syphon source for x86_64 and arm64, each with LC_BUILD_VERSION minos 13.0.
- Metal shader compilation targets air64-apple-macos13.0.
- Replaced macOS 14 onChange overloads and ContentUnavailableView with compatible implementations.
- Native NDI runtime remains optional/external; its OS compatibility depends on the installed runtime.

## Performance evidence

- Moved editor tab selection out of OperatorView so switching a page does not invalidate the cue/playback columns through parent state.
- Replaced segmented/menu ViewThatFits negotiation with a stable editor header.
- Font combo box uses a native data source instead of inserting the entire font catalog when each editor is created.
- Bounded row-height cache (12,000 strings), invalidated by text or width; unchanged numeric fields and selection values no longer emit redundant updates.
- Grouped layout drag edits into one undo operation and removed repeated select/focus notifications while dragging.
- NDI connection count publishes only when it changes (regression test: 240 unchanged updates produce no extra notifications).
- Syphon/NDI target validation runs only when output/canvas configuration changes; session changes and incompatible settings still stop output. Syphon lifecycle test verifies stable streaming, live layout change, and stop on FPS change.
- 3,000-row height workload: cold pass 0.57–0.66 s, cached pass 0.026–0.030 s on this host. This measures text-height computation, not total Silicon UI latency.
