# v0.5.5 build 17 — 2026-11-12

## Changed / Implemented

- Surtitle headers have an X delete button and an = drag handle, like cue rows. Drag onto another header to take its position or onto the trailing space to move last; context menu also offers Move Left / Move Right. Keep at least one Surtitle. Undo restores deletion/reordering.
- New document imports create text columns automatically by source names. Source IDs and cue numbers are automatic; Group / Status is ignored. Existing name collisions receive a numeric suffix. Empty initial projects reuse the blank initial Surtitle.
- One import page includes automatic preview, Import button, and insertion choice: append (default) or after a selected cue number. Duplicate numbers are disambiguated by row and resolved to UUID. Current cue selection does not silently control insertion.
- Main and floating control windows disallow native full screen, retain resizing and normal zoom/maximize. Physical output windows are unchanged.

## Architecture

Surtitle changes use existing project history. When the first column changes, legacy cue.text storage is rebased to the new first layer; texts remain associated with language UUIDs. Deletion removes style/output/import references. Project format remains 12.
